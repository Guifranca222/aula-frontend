Alunos Iniciam projeto de página pessoal

26 de setembro de 2026 | Às 10h23

Os estudantes de ADS na aula de frontend iniciaram o projeto de página pessoal.

O projeto utiliza titulos, paragrafos, imagens, links, páginas, estudos e projetos.

Na próxima etapa, os estudantes aplicaram CSS para estilizar a página.
